# Experimental Hardware Platform

## OAIBOX™

The OAIBOX™ platform, developed by Allbesmart, was used to host the OpenAirInterface software environment, including the gNB and 5G Core Network.

## USRP B210

The USRP B210 was connected to the OAIBOX through USB 3.0 and acted as the software-defined radio front-end.

## Quectel RM520N-GL

The Quectel RM520N-GL modem was used as the User Equipment (UE), connected to a host computer for configuration and testing.

## Laboratory Setup

The experimental environment combined the OAIBOX platform, radio equipment, UE modem and Ethernet connectivity to the institutional network.

Photographs in this section document the actual equipment and laboratory setup used in the project.
