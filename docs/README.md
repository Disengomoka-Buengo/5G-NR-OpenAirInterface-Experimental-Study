# Project Documentation

## 1. Project Overview

This project presents an experimental study of a 5G New Radio Standalone (5G NR SA) network implemented using OpenAirInterface (OAI) on the OAIBOX™ platform.

The study focused on understanding the architecture, configuration and operation of a 5G network through practical laboratory experiments.

## 2. Main Objectives

- Understand the 5G NR Standalone architecture.
- Explore the interaction between the gNB and the 5G Core.
- Evaluate the impact of radio configuration parameters on network performance.
- Analyse signalling procedures and packet traffic using Wireshark.
- Investigate 5G security mechanisms.
- Explore network slicing and private PLMN configuration.

## 3. Experimental Methodology

The project was conducted through controlled laboratory experiments, changing selected radio and network parameters and observing their impact on performance indicators and network behaviour.

The methodology combined theoretical analysis, practical configuration, packet inspection and experimental measurement.

## 4. Experimental Areas

The study included ten laboratory experiments covering radio bandwidth, carrier frequency, TDD, FDD, MCS, MIMO, protocol inspection, 5G security, network slicing and PLMN/SIM programming.

## 5. Project Outcome

The experimental work provided practical experience with a 5G NR Standalone environment, including radio access, 5G Core procedures, protocol analysis and network performance evaluation.
